kumokagi 雲鍵 — Backend-agnostic ephemeral secrets management

Active development, 2026

Go and Python library + CLI for fetching secrets at runtime from any cloud backend — Vault, AWS Secrets Manager, Azure Key Vault, GCP Secret Manager, 1Password — without ever writing them to disk, env vars, or container manifests.

  • Single interface, any backend: swap Vault for AWS Secrets Manager by changing one config line; identical API in Go and Python.
  • Ambient identity only: IRSA, Workload Identity, op signin — no long-lived API keys, no credential sprawl.
  • Ephemeral by design: secrets live in process memory only; credential rotation is automatic on next process start.
